# For Study

The original 16 scenes (`Scenes/Final/16 Scenes`), kept for the record and ready to run again. Scripts, prefabs, boards, and recordings are the original files. The original Realtime client is the package in `Packages/com.mapluisch.openai-realtime-api-for-unity`.

1. Provide an OpenAI key: environment variable `OPENAI_API_KEY`, or a file `openai_api_key.txt` next to the `Assets` folder (Editor) or in the app's persistent data folder (headset). The key fields in the scenes are empty on purpose.
2. Build one scene for Android, or press Play. X, Y, left trigger, A, B, right trigger (or keys 1 to 6) select an avatar and start the session.

The All-in-One demo reuses the recordings and boards from here; otherwise this folder is independent of `For Demo`.
